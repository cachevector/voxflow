# Marketing graphics

Three feature images, built from the product type, palette, and overlay
pill so the words stay exact.

| File | Size | Use |
| --- | --- | --- |
| `feature-hero.png` | 1920 x 1080 | Site, X, LinkedIn, Product Hunt cover |
| `feature-ondevice.png` | 1920 x 1080 | Privacy / on-device story |
| `feature-square.png` | 1080 x 1080 | Instagram, X post, avatar-adjacent |

Rebuild after a copy or brand change:

```bash
python3 docs/marketing/render.py
```

Needs Google Chrome on macOS. Output is written next to this file.
